## ❓ QUESTIONS COURANTES

**Q: "Comment ça fonctionne?"**
A: React + Electron pour créer une app Windows. Stockage local, pas de cloud requis.

**Q: "Mes données sont-elles sûres?"**
A: OUI! Tout est stocké localement sur votre PC, rien ne sort.

**Q: "Je peux modifier le code?"**
A: OUI! C'est du code source complet. Lisez les fichiers dans `apps/desktop/src/`

**Q: "Comment partager avec d'autres?"**
A: Générez l'EXE (`npm run build`), puis partager le `.exe` file.

**Q: "Puis-je ajouter mes propres versets?"**
A: OUI! Éditez `apps/desktop/src/data/spiritualData.ts`
