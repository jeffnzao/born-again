🚀 Commençons!

1. Installation

npm install

2. Mode Développement

Option A: Web uniquement

npm run dev

Accédez à http://localhost:5173

Option B: Web + Desktop (Electron)

npm run dev:all

3. Build Final (EXE Windows)

npm run build

Les fichiers .exe seront générés dans le dossier release/

🎨 Personnalisation

Changer l'icône

Remplacez public/icon.svg par votre propre icône (256x256+)

Modifier les versets bibliques

Éditez les sections dans src/App.tsx

Changer les couleurs

Modifiez le thème dans tailwind.config.js

❓ Problèmes Courants

❌ "Application ne s'ouvre pas"

Solution: Vérifiez que le dev server Vite tourne sur le port 5173

npm run dev

❌ "Build EXE échoue"

Solution: Nettoyez et réinstallez

rm -rf node_modules dist dist-electron
npm install
npm run build

❌ "Module Electron non trouvé"

Solution: Réinstallez electron

npm install electron --save-dev
